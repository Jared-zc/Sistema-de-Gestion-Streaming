# Sistema-de-Gestion-Streaming

Proyecto desarrollado para gestionar usuarios, contenidos, suscripciones y reproducciones de una plataforma de streaming.

## Objetivo

Desarrollar un sistema de gestión de streaming aplicando programación funcional y una estructura modular.

## Tecnologías

- Python
- Git
- GitHub

## Módulos

- Gestión de usuarios
- Gestión de contenido
- Gestión de suscripciones
- Gestión de reproducciones
- Reportes

## Estructura

- docs: documentación del sistema
- src: código fuente
- tests: pruebas del sistema
