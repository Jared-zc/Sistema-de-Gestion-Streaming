# Planeación del Sistema

## Nombre del sistema

Sistema de Gestión de Streaming

## Objetivo general

Desarrollar un sistema que permita administrar usuarios, contenidos multimedia, suscripciones y reproducciones.

## Módulos

- Usuarios
- Contenido
- Suscripciones
- Reproducciones
- Reportes

## Programación funcional

El sistema utiliza funciones independientes para procesar los datos.
